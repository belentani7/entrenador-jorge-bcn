# ADR-001 — Mantener la aplicación full stack existente

- Estado: Aceptada para esta implementación.
- Contexto: El repositorio ya contiene una landing React, procedimientos tRPC y persistencia MySQL para leads y reservas.
- Decisión: Construir sobre client/src/pages/Home.tsx y server/routers.ts, manteniendo los límites actuales.
- Consecuencias: No se duplica la lógica de captación. La publicación funcional sigue necesitando la configuración de base de datos y correo descrita en el repositorio.
